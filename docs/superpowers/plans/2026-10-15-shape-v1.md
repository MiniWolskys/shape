# Shape v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Shape v1: a static React app that turns pictures into window-shaped Minecraft paintings and exports a single library pack (library + datapack + resource pack + SHA1).

**Architecture:** Pure, unit-tested TypeScript modules (`domain`, `imaging`, `packs`) hold all logic and work on a plain `Raster` type and PNG bytes. React screens read and write two Zustand stores (workspace, editor) and never contain business rules. The workspace autosaves to IndexedDB; nothing leaves the browser except downloads.

**Tech Stack:** Vite 8, React 19, TypeScript 6 strict, Zustand 5, fflate (zip + deflate), idb-keyval, Vitest 5 + Testing Library + jsdom, oxlint, Prettier, GitHub Actions → Pages.

**Spec:** `docs/specs/2026-10-15-shape-design.md`. Visual reference: `docs/design/design-proposal.html` (direction A “Lantern Workshop”, Dusk tone; ignore its old names “Paneworks/Easelcraft”, the app is **Shape**).

## Global Constraints

- App name `Shape`, tagline `Minecraft paintings` (EN) / `tableaux Minecraft` (FR). Vite `base: '/shape/'`.
- Data pack `pack.mcmeta`: `min_format: 121`, `max_format: 121`. Resource pack: `min_format: 97`, `max_format: [97, 1]`.
- Painting size 1–16 blocks per side; pixels per block integer 1–64, presets 16/32/64.
- Painting IDs match `^[a-z0-9_]+$`; namespaces match `^[a-z0-9_.-]+$`. IDs never change once created.
- Library pack file name `<namespace>-v<version>.zip`; JSON entry `shape-library.json` with `formatVersion: 1`.
- Zips are deterministic: entries sorted by path, every entry mtime `1980-01-01T00:00:00`, so identical content → identical bytes → identical SHA1.
- Transparent (`out`) pixels get alpha 0 and RGB = frame material color (dark oak when frame is `none`).
- Every user-visible string goes through i18n with both `en` and `fr` entries; the TypeScript type of the dictionary makes a missing French key a compile error.
- Colors only from CSS tokens in `src/theme/tokens.css`. Paintings are always drawn on neutral grey backdrops, never on the brown UI.
- No `any`, no non-null `!` on values that can really be missing, no silent `catch {}`. Format with Prettier, lint clean with `oxlint --deny-warnings`.
- Commit after each task with a message ending in `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Run `npm run format && npm run lint && npm run typecheck && npm test` before each commit.

## Review Focus

1. **Huge or odd source images** (8000×6000 photo, 1×1 px image, transparent PNG, non-image file renamed `.png`): the editor must stay responsive (downscale sources to at most 2048 px on the longest side on import) and unreadable files must show “This file isn't an image Shape can read.” → tests in Task 3 (`fitWithin`) and Task 10 (import error).
2. **Opening a library pack from an older/newer/foreign source** (missing `shape-library.json`, `formatVersion: 2`, a random zip, a different namespace): clear error, workspace untouched → tests in Task 6 and Task 2.
3. **Changing size or resolution after pixel edits**: edits are resampled, not lost or misaligned → test in Task 4 (`resampleEdits`).
4. **Re-exporting unchanged content**: same SHA1 both times, so players don't re-download for nothing → test in Task 6.
5. **Published painting protections under every path** (delete button, size picker, import of an older pack that lacks it): it stays in the library and in every export → tests in Task 2 and Task 12.

import type { Random } from './types.ts'
const ALPHABET = 'abcdefghijklmnopqrstuvwxyz0123456789'
const randomChars = (n: number, random: Random) =>
  Array.from(
    { length: n },
    () => ALPHABET[Math.floor(random() * ALPHABET.length) % ALPHABET.length],
  ).join('')
const baseSlug = (text: string) =>
  text
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, '_')
    .replace(/^_+|_+$/g, '')
export function slugify(text: string): string {
  return baseSlug(text).slice(0, 24).replace(/_+$/, '') || 'painting'
}
export function makePaintingId(title: string, random: Random): string {
  return `${slugify(title)}_${randomChars(3, random)}`
}
export function makeAssetId(random: Random): string {
  return randomChars(12, random)
}
export function isValidNamespace(ns: string): boolean {
  return /^[a-z0-9_.-]{1,64}$/.test(ns) && ns !== 'minecraft'
}
export function namespaceFromName(name: string): string {
  return baseSlug(name) || 'paintings'
}
