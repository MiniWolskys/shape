Design proposal · revision 3 · working name “Easelcraft”

A painting workshop for our Minecraft server

Everything the app has to do, how each step should feel for a player who has never used an image editor, and three visual directions shown across the same five screens. Pick a direction, or mix parts of them, and I'll write it up as the spec.

1 · What I understood

The brief, in short

You said

  • A static web app on GitHub Pages, deployed by CI. No backend, no login, nothing stored on the site.
  • Export is one library pack: the library, the datapack, the resource pack and the SHA1 in a single file, easy to pass between you and to reopen in the app.
  • Someone with no library can just create a painting, and add it to a library later by opening that library.
  • Published paintings are locked, IDs never change, importing only adds.
  • Window-inspired transparency shapes: circle, church stained glass, other window ideas.
  • New: change pixel colors by hand or by group, with a color picker and presets, for example to make them transparent.
  • Production quality, easy for everyday Minecraft players. Warm, wood and orange look, open to other ideas.

I'm assuming (please correct)

  • “Both optional” means both Secondary features ship in v1: basic image editing and the Minecraft look filter.
  • Pack formats come from your 26.3 test packs: data 121, resources 97. Every export also writes the minecraft:placeable tag with "replace": false, like the test datapack does.
  • Transparency needs the Transparent Paintings mod. Players without it see hidden pixels as opaque, so the app decides which color those pixels get.
  • Desktop first. On a phone you can browse a library and export, but editing is built for a mouse or trackpad.
  • React + TypeScript + Vite, deployed to Pages with GitHub Actions. That part is mine to handle.

3 · Flow

How a player moves through it

Four screens. The editor is a guided sequence of five steps, but every step stays clickable, so experienced players can jump straight to the one they want.

HomeCreate a painting, open a library pack, or resume a draft.
→
LibraryAll paintings as cards. Add, edit, import a friend's pack.
→
EditorImage · Size & crop · Window & frame · Colors & pixels · Details
→
ExportPick, check, download one library pack, follow the server steps.

How the editor builds a painting

Three layers, always combined in this order. Going back to an earlier step never throws away later work.

1 · PictureYour image, crop, rotation, brightness and contrast, Minecraft look filter.
+
2 · Window & frameGenerated from the shape and frame settings. Change the shape any time and it redraws.
+
3 · Your pixel editsPainted on top and kept when you change the shape or the picture's brightness.
4 · Window shapes

Shape catalogue

Each shape is generated at the painting's resolution, not stretched from a template. These are drawn live at 32 px per block on a checkerboard, so you see exactly which pixels are transparent. Leaded shapes tint the picture like coloured glass.

6 · Decisions

Settled so far

  1. Look: A · Lantern Workshop, Dusk tone only, with pixel-crisp painting previews and Minecraft dye presets.
  2. Painting backdrop: paintings always sit on a neutral grey, never on the brown interface. The editor has a backdrop switch (Auto, Light, Dark, Sky). Auto picks the checkerboard that contrasts with the chosen frame, so thin frames stay visible.
  3. Published paintings: the image can be replaced later. Size and ID stay locked, and the painting can't be deleted.
  4. Languages: English and French, following the browser language, with a switch in the top bar.
  5. Library pack: a plain .zip, e.g. ourpaintings-v8.zip, so Windows opens it with no extra tool.

Still open: the app name

“Easelcraft” is a stand-in. Candidates built on workshop and painting:

  1. Easelcraft (my pick). Painting plus “craft”, which feels native to Minecraft and reads the same in French.
  2. Lantern Atelier. “Atelier” is the workshop word in both English and French, and it ties to the Dusk lantern look.
  3. Block Atelier. Says “Minecraft painting studio” in two words.
